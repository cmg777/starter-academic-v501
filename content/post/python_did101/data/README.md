# Data dictionary - Tutoring and GPA in 35 high schools (DiD tutorial)

Companion data for the tutorial <em>Introduction to Difference-in-Differences (DiD) in Python</em>, which uses the simulated case study of Corral and Yang (2024). In one region, <strong>10 of 35 high schools</strong> adopt an after-school tutoring program for low-income students at the same time; the other 25 schools never adopt it. The outcome <code>gpa</code> is the school's average GPA of low-income students. In the 2×2 file, treated schools rise from 60.17 to 96.37 (a naive change of 36.20 points) while comparison schools rise from 71.22 to 82.10 (10.89 points), so the DiD estimate of the average treatment effect on the treated (ATT) is <strong>25.315</strong> GPA points (25.32 from the rounded means). The event-study file follows the same 35 schools for 8 periods with adoption in period 5; its event-time coefficients are 0.34, &minus;0.32 and 0.59 before adoption and 25.03 to 25.70 after.


Companion data for the post <https://carlos-mendez.org/post/python_did101/>. Each dataset ships as a labeled Stata `.dta` (v118) plus its source file. Generated by `build_data_dictionary.py`.

## Known limitations & caveats

- <strong>Simulated, not observed.</strong> The schools come from the teaching example of Corral and Yang (2024), built to illustrate DiD mechanics. The R² near 0.99 and a 25-point effect on GPA are far larger than real tutoring programs produce.
- <strong>GPA can exceed 100.</strong> <code>gpa</code> is described as a 0–100 score, but the simulated event-study values reach 107.68 (the 2×2 file stays below 100, maximum 99.15). Treat it as a continuous score, not a bounded grade.
- <strong>timeToTreat is missing by design</strong> for the 25 comparison schools. Software that drops rows with missing values (pyfixest, fixest, Stata's <code>i.</code> operator) silently removes every comparison school; fill it with a placeholder or build the event dummies by hand.
- <strong>Two independent simulations.</strong> The 2×2 file is not periods 4 and 5 of the event-study file, so estimates from the two files differ (25.315 vs. a collapsed 24.897).
- <strong>female_share varies within schools over time.</strong> It is a time-varying covariate; the post uses it only as a robustness check (it moves the DiD estimate by 0.013).
- <strong>CSV values carry full float precision.</strong> The original .dta files store <code>gpa</code> and <code>female_share</code> as single-precision floats; the CSVs write those exact values as doubles (17 significant digits). In Stata, read the CSV with <code>import delimited …, asdouble</code>.
