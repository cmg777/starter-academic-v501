# Approved scope — `r_estimateW`

Archived from the plan approved before implementation began. Downstream pipeline
stages read this file instead of re-negotiating scope.

## 1. TOPIC

Bayesian estimation of the spatial weight matrix with the **estimateW** R package
(Krisztin & Piribauer 2026), applied to the built-in `nuts1growth` panel: 90
European NUTS-1 regions, 2001–2019, T = 19, 1,710 observations, Eurostat via the
package.

Analysis question: **"Which European regions actually behave as each other's
neighbours for productivity growth — and does it matter whether we assume that
map or estimate it?"**

## 2. LANGUAGE

**R** — `estimateW` 0.2.0 is R-only (pure R, no compiled code of its own).
Canonical script `analysis.R`, run with
`Rscript analysis.R 2>&1 | tee execution_log.txt`.

## 3. FIGURE THEME

**Dark navy.** `BG #0f1729`, `GRID #1f2b5e`, `TEXT #c8d0e0`, `WHITE #e8ecf2`,
`STEEL #6a9bcc`, `ORANGE #d97757`, `TEAL #00d4c8`. `ggsave(..., dpi = 300, bg = BG)`;
`circlize` chord diagrams go through a `png(bg = BG)` + `par()` helper because
`ggsave()` cannot save base graphics.

## 6. FRAMING

**Descriptive / associational.** This is a spatially augmented growth regression,
not a causal design: there is no treatment and no ATE/ATT-family estimand. The
reported direct, indirect and total "impacts" are model-implied marginal effects
under the fitted SAR, not causal effects. The script header states this; the post
repeats it in the Discussion.

## 7. DECISIONS TAKEN

- **MCMC.** Reproduce the paper exactly (`set.seed(571)`, `niter = 200`,
  `nretain = 100`) for the headline table, then run two longer independent chains
  sized to a time budget so Gelman-Rubin R-hat is available. The headline chain is
  never thinned, shortened or parallelised — all three change the RNG stream and
  destroy the Table 3 comparison.
- **Audience.** Assume neither spatial econometrics nor Bayesian statistics; build
  both from zero. Longest-post option, maximum concept cards.
- **Extras, all four.** Prior architecture; ground-truth simulation; model
  taxonomy tour; estimated-vs-exogenous W benchmark with a map of Europe.
- **Geometry.** Fetch GISCO NUTS-1 once, cache the `sf` object in the bundle so
  re-runs are offline. `giscoR` and `spdep` are deliberately not used
  (`sf::st_read` + `st_touches` suffice); `igraph`/`ggraph` are deliberately not
  used (classical MDS + `geom_curve` suffice).
- **Source paper.** Moved to `references/` and gitignored — CC BY 4.0, but not
  republished from this site.

## 8. RISKS AND EDGE CASES ADDRESSED

1. `sarw()` return shapes — verified empirically: `postb` is (parameter × draw),
   `postw` is `[i, j, draw]`; `slxw` returns no `rho`, `semw`/`sdemw`/`slxw`
   return no impact decomposition.
2. Runtime — two-point timing probe, escalation ladder, keyed RDS cache split
   into committed `_slim` and gitignored `_full`.
3. Reproduction — MCSE-based audit reporting `exact` / `within_mc_noise` /
   `differs`, capped at the paper's 5-decimal print precision.
4. `install.packages()` under `Rscript` — CRAN repo guard as the first
   executable statement (`repos` is `@CRAN@` on this machine).
5. Queen-contiguity isolates (islands) — repaired with the nearest centroid
   neighbour and logged by name.
6. `X` and `Z` must be disjoint in the Durbin/SLX families — `estimateW` builds
   `U = [X, WX, Z]` and does **not** error on a rank-deficient design.
7. Colour accessibility — the paper's Southern (orange/brown) and CEE (light red)
   families are hue-adjacent; ramps are biased apart and region ordering carries
   group identity on every axis.
8. Jensen error — the multiplier is averaged per draw, never computed from the
   posterior mean W and mean rho.
