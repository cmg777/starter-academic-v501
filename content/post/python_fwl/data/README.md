# Data dictionary - Simulated retail stores (FWL tutorial)

Companion data for the tutorial <em>The FWL Theorem: Making Multivariate Regressions Intuitive</em>, inspired by Courthoud (2022). The file holds <strong>50 simulated stores</strong> built so that the answer is known in advance: coupons raise daily sales by exactly <strong>+0.2</strong>, but neighborhood income lowers coupon usage and raises sales, so it confounds the comparison. Ignoring income, the slope of sales on coupons is &minus;0.1059 (p = 0.365); controlling for income it becomes +0.2673 (p = 0.031), and the <strong>Frisch&ndash;Waugh&ndash;Lovell (FWL) theorem</strong> recovers the same +0.2673 from a regression of residualized sales on residualized coupons.


Companion data for the post <https://carlos-mendez.org/post/python_fwl/>. Each dataset ships as a labeled Stata `.dta` (v118) plus its source file. Generated by `build_data_dictionary.py`.

## Known limitations & caveats

- <strong>Simulated, not observed.</strong> The 50 stores come from a known data-generating process with a true coupon effect of +0.2 by construction. The file illustrates confounding and the FWL theorem, not a real retail market.
- <strong>Generated in Python with numpy's PCG64 generator</strong> (<code>np.random.default_rng(42)</code> in <code>script.py</code>). <code>sales</code>, <code>coupons</code> and <code>income</code> are rounded to 2 decimals, and every estimate in the post is computed on these rounded values.
- <strong>Load this file to reproduce the post in R or Stata.</strong> Native simulations with seed 42 (<code>set.seed(42)</code> in R, <code>set seed 42</code> in Stata) use different random-number generators, so they produce different draws and different estimates. Read <code>fwl_store_data.csv</code> or <code>fwl_store_data.dta</code> instead of re-simulating.
- <strong>Small sample.</strong> With n = 50 the controlled estimate (+0.2673, SE 0.1203) is close to, but not equal to, the true +0.2; the naive slope (−0.1059) sits near its population limit of −0.10.
- <strong>dayofweek is a bare 1–7 index.</strong> The simulation attaches no weekday names to the codes, and the variable enters the data-generating process linearly (slope +0.5). It is drawn independently of income and coupons (sample correlation with coupons −0.076).
- <strong>No store identifier.</strong> Rows are in the order the stores were drawn; there is no id column.
