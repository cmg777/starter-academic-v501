# Data dictionary - Evaluating the Impact of the Jamuna Bridge

Companion data for a hands-on Python tutorial that evaluates the economic impact of the <strong>Jamuna (Bangabandhu) Bridge</strong>, a 4.8&nbsp;km crossing that opened in June 1998, cost about US\$985 million, connected roughly 26&nbsp;million people in isolated northwest Bangladesh to Dhaka, and cut freight costs by about half. The design is a two-group, non-staggered <strong>difference-in-differences</strong>: the <strong>Jamuna hinterland</strong> is treated, and the <strong>Padma hinterland</strong> &mdash; a symmetric region cut off by the other great river, whose own bridge was not started until 2015 &mdash; is the comparison. The Dhaka&ndash;Chittagong core is excluded. These five files are tidy CSV exports of the authors' original Stata replication package, unchanged in value; only the file format and column selection differ. The tutorial reproduces all 122 published coefficients to three decimals.


Companion data for the post <https://carlos-mendez.org/post/python_bridge_impact/>. Each dataset ships as a labeled Stata `.dta` (v118) plus its source file. Generated by `build_data_dictionary.py`.

## Datasets

| File | Grain | Rows x Cols | Purpose |
|---|---|---|---|
| `bridge_nightlights` | one row per upazila x three-year period | 2,513 x 13 | The running example of the tutorial: the richest panel, used to teach the 2x2, two-way fixed effects, the event study, both doubly-robust estimators, and the sensitivity analysis. |
| `bridge_employment` | one row per upazila x census year | 1,053 x 20 | Carries population density and the sectoral employment shares — including the density variable that discriminates between the backwash and comparative-advantage theories. |
| `bridge_yield` | one row per former district x three-year period | 128 x 13 | Agricultural productivity — the outcome where the spatial heterogeneity is most dramatic, with the farthest distance band gaining 26.5 percent against 4.9 percent nearest. |
| `bridge_dhs_household` | one row per village (survey cluster) x survey year | 1,543 x 20 | The public-goods placebo. Tests the rival political-economy explanation that a prime minister with roots in the Jamuna hinterland simply sent more services there. |
| `bridge_dhs_village` | one row per village (survey cluster) x survey year | 1,455 x 22 | The infrastructure half of the public-goods placebo: distances to schools, clinics, headquarters, and the presence of banks, cooperatives and NGO programmes. |

## Known limitations & caveats

- <strong>year is a period index, not a calendar year.</strong> Nightlights and yields are averaged into three-year blocks. The mapping is in the <code>year</code> row of each dataset below. Because the controls interact baseline traits with this index, substituting calendar years changes every coefficient.
- <strong>smp1 is the sample filter, and it is deliberately missing.</strong> It is missing for the Dhaka–Chittagong core region (<code>treatd == 1</code>), which is neither treated nor a credible comparison. Filtering on <code>smp1.notna()</code> is how the core is excluded from every regression. In the two DHS files there is no core, so <code>smp1</code> is identical to <code>treat</code>.
- <strong>Distances are to the relevant crossing.</strong> <code>mdist = min(jamuna_m, padma_m)</code> gives each upazila its distance to the Jamuna bridge if it is in the treated hinterland, or to the planned Padma crossing if it is in the comparison hinterland. It is not distance to a single point.
- <strong>The yield panel is very thin.</strong> Sixteen former districts, of which eleven enter the estimation and nine survive the negative-weight drop. Cluster-robust inference with nine clusters is fragile; treat the yield magnitudes as indicative.
- <strong>The census panel has one pre-bridge year.</strong> Only 1991 precedes the bridge, so no pre-trend test is possible for population density or the employment shares — only a level-balance test. This includes the density variable that settles the paper's theoretical question.
- <strong>Village-questionnaire columns named like presence indicators are often distances.</strong> <code>post_office</code> and <code>cinema</code> are labelled as distances in the original Stata data despite being filed under &ldquo;Presence of&rdquo; in the published table. <code>grameen_bank</code>, <code>co_operative_soc</code> and <code>NGO</code> are genuine presence dummies.
- <strong>Missingness is heavy in the village file.</strong> <code>dist_satellite_clinic</code> (398 non-missing), <code>NGO</code> (413), <code>dist_Thana</code> (559) and <code>dist_district</code> (618) are far from complete, which is why the public-goods regressions have wildly different sample sizes.
- <strong>These are the authors' data, unchanged.</strong> Values are byte-faithful to the original <code>.dta</code> files; only the format and the column selection differ. Any error in the source data is preserved here.
