## The R bundle was cleaner than the Python one

Two of the hazards that shaped the Python pass do not exist here:

- **Zero pre-existing uses of "stage"** anywhere in the R bundle, so nothing had to be reworded
  out of the way (the Python side had two "which stage failed" sentences about `Mlsynth*Error`
  types, which became "which phase failed").
- **No `Step-1` / two-step collision** — that was a `TSSC`/Li–Shankar artefact, and the R post
  reaches demeaned SC through `synthdid`'s `omega.intercept` instead.

`ai-slides.pdf` was checked and contains no occurrence, so the binary needed no regeneration.

## Four hand-fixes

- §15 `Which rung should you stand on?` → **"Which stage should you choose?"**
- §1 "puts them on a single ladder and asks which rung to stand on" → "…which stage to choose".
- "reproduces R to five decimals **on** every rung it can fit" → "**at** every stage" (`index.md`
  §16 and `README.md`).

## One figure had the word baked in

`analysis.R:969` set a ggplot title of *"Every rung of the ladder puts the Brexit cost above
2.4%"*, which is rendered into `r_sc_dsc_sdid_15_att_dotplot.png` — the figure used in post §14
**and on deck slide 19, whose own title now reads "Every stage beats 2.4%"**. Leaving the PNG
stale would have put the two words side by side on one slide.

A full `analysis.R` re-run was not possible: R 4.5.2 is installed but **`synthdid` and `masc` are
not**. Figure 15 does not need them — its data is `att_headline.csv`, which is committed. It was
regenerated by a standalone script that copies `SLUG`, the dark palette, `theme_site()` and
`save_fig()` **verbatim** from `analysis.R` (lines 79–127) and reproduces the `p15` block with
only the title's wording changed. Output is 2700×1800 px at 300 dpi, identical to the original,
and every plotted value still matches `att_headline.csv` (4.98/6.18, 3.06/4.20, 2.98/4.12,
2.76/3.89, 2.79/3.92, 2.79/3.92, 2.73/3.83, 3.04/4.19).

The other 17 figures contain no text with the word and were left untouched.

## Noticed, not changed: the two editions number the ladder differently

Now that both say "Stage", a pre-existing mismatch is easier to see:

- **R post** — `## 7. Stage 1 — Difference-in-differences` … `Stage 6 — Augmented SC` (**1–6**)
- **R deck** — `## Stage 0 — Difference-in-differences` … `Stages 4 and 5` (**0–5**)
- **Python post and deck** — **0–5** throughout

This predates the rename; the substitution preserved whatever number each heading already
carried. Aligning the R post to 0–5 would make all four artifacts agree, but renumbering
sections is a separate decision from renaming a word, so it was left alone.
