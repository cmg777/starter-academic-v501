# 2026-10-05: python_sc101, an introduction to synthetic control in Python with mlsynth

The new post `content/post/python_sc101/` is the Python twin of `content/post/stata_sc`. It introduces the synthetic control method and the Python library mlsynth with the California Proposition 99 case. It replicates every step of the Stata benchmark and adds a short tour of three other mlsynth estimators.

The scope came from six rounds of questions with the user. The approved plan is in `~/.claude/plans/pasted-content-id-7f8d-using-the-velvet-quiche.md`. The same day also corrected and restyled `stata_sc` (see `2026-10-05-stata-sc-errata-restyle.md`).

## Replication of the Stata benchmark

| Quantity | Stata `synth2` | mlsynth 1.0.0 |
|---|---|---|
| Donor weights (UT, NV, MT, CO, CT) | 0.334, 0.235, 0.202, 0.161, 0.068 | 0.335, 0.236, 0.202, 0.160, 0.068 |
| ATT 1989–2000 | −19.00 | −18.98 (−19.00 with the rounded Stata weights) |
| Pre-treatment RMSE | 1.756 | 1.754 |
| Placebo rank and p-value | 1 of 39, 0.026 | 1 of 39, 0.026 |
| cut(2) | 20 states, p = 0.050 | the same 20 states, p = 0.050 |
| In-time placebo, gaps 1985–1988 | −3.33, −3.59, −8.65, −8.39 | −3.31, −3.57, −8.64, −8.37 |
| Leave-one-out, gaps in 2000 | −28.35 to −23.49 | −27.15 to −23.48 |

The predictor weights V differ completely while the donor weights agree. The post teaches this as a problem of identification, not as an error. Feeding the Stata V into the inner problem recovers the Stata W, which shows that many V select the same donor weights.

## Lessons and gotchas

- **mlsynth 1.0.0 listwise deletion.** When every covariate window is identical, the PyPI build drops every year in which any covariate is missing, which gives an ATT of −18.55. Distinct windows for the lag columns avoid it.
- **Placebo designs differ.** The built-in placebo of mlsynth leaves California out of every placebo pool and ranks the RMSPE ratio, while synth2 keeps California in the pool. The post runs both, and they agree on the rank.
- **Seed sensitivity.** Several placebo fits depend on the seed of the outer V search. With seed 42 the cut(2) set equals the 20 Stata states, and with seed 0 South Dakota enters.
- **SDID in 1.0.0.** The config takes only `B` and `seed`, the unit and time weights are not exposed, and the counterfactual is already level-adjusted.
- **Academicons 1.9.0 has no `google-colab` glyph.** The button uses `ai open-data` instead; the Colab button of `python_did101` renders blank for the same reason.
- **Hugo page resources.** A Markdown resource may begin with only one HTML comment block, or the build stops with "starting HTML comment with no end".
- **Stata on this machine.** StataNow MP is not licensed, so batch jobs use Stata 19 SE, and synth2 overwrites the global scalars `att`, `rmse`, `r2`, `mse`, and `mae`.
- **tidysynth.** Its placebo fits reuse the V of California, which is why cut(2) keeps only 7 units in R.
- **AhaSlides import.** A Start click on a stale dialog reference was silently lost; a fresh reference after the upload settled worked.
- **regen_companions.py.** Its parser of the `links:` list assumed indented items, so it missed the column-0 list and the AhaSlides link. The boundary now skips lines that start with a dash.
