# WebApps (`/webapps/`)

The WebApps section (`content/webapps/` + its `content/es/` and `content/ja/` counterparts) lists every interactive app on the site as a filterable card grid — each card opens the app itself in a new tab.

## Architecture (two sources + a shared catalog + a capture script)

- **Standalone apps** — one page bundle per app in `content/webapps/<slug>/` (Google Earth Engine dashboards and the Streamlit apps of `geometrics`/`expdpy`). Each `index.md` carries `app_url` (the URL the card opens), `platform: gee|streamlit`, an optional `region` (`global`, `bolivia`, `cambodia`, `indonesia`, `japan`), a `topic` id from `data/tutorial_topics.yaml` (e.g. `gis-rs`, `panel-fe`, `spatial`), `_build: {render: never, list: always}` (listed only — there is no app detail page), `links:` for the tutorial or package page (GEE source code is never linked publicly — it is kept as a `# Source code (GEE), not shown on the site: <url>` front-matter comment), and a short `**Cite as:**` line in the body. The card image is the bundle's `featured.jpg`.
- **Tutorial apps** — `layouts/section/webapps.html` also auto-lists every English tutorial bundle that ships `web_app/index.html` (title/summary from the current language's tutorial stub, image from the tutorial's featured image, topic from the first matching `category_matches` in `data/tutorial_topics.yaml`). Adding a `web_app/` folder to a tutorial is all it takes — no entry file.
- **List layout** — `layouts/partials/catalog.html` (shared with `/books/`, `/software/` and `/data/`): a search box plus one dropdown per entry in the section `_index.md` `filters:` front matter (`platform`, `region`, `topic` for WebApps), and an optional `year_filter`. A new `region` or `topic` value needs an option in the `filters:` list of all three `_index.md` files (translated `label`, identical `value`).
- **Thumbnails** — `scripts/capture-dashboard-screenshots.cjs` (Playwright headless Chromium) loads each public app, waits for it to paint, and writes a 16:9 JPEG to `content/webapps/<slug>/featured.jpg`, then copies it byte-for-byte into `content/es/webapps/<slug>/` and `content/ja/webapps/<slug>/` (page-bundle resources do not cross languages; the app UI is English, so one capture serves all three). Its `APPS` array lists every captured app (the Google Earth Engine apps): GEE apps default to `https://carlos-mendez.projects.earthengine.app/view/<slug>`; other hosts give an explicit `url`. Streamlit apps are not captured — their maps render in nested iframes that headless Chromium leaves blank — so each Streamlit bundle reuses its package's `content/software/<pkg>/featured.webp` as `featured.webp`. **The `.cjs` header documents the `--slug`/`--wait` flags — read it before editing the script.**
- The old dashboards gallery page (`content/projects/dashboards/` with `{{< dashboard-gallery >}}`/`{{< dashboard-card >}}`) no longer exists; `/projects/dashboards/` is an alias of `/webapps/`. The two shortcodes and their CSS remain in `layouts/shortcodes/` and `assets/scss/custom.scss` but are unused.

## Trigger: "Add web app: `<App URL>` — `<English title>`"

The typical input is the published app URL (a GEE `…/view/<slug>` link or a Streamlit `https://<name>.streamlit.app/` link) plus an English title. Default the citation author to Carlos Mendez and ask only if a **co-author**, a **source-code URL**, a **region** or a **topic** is unclear:

1. **Slug** — for a GEE app, the last path segment of the URL (`…/view/<slug>`); for another host, a short kebab-case name (e.g. `geometrics-explore`).
2. **English bundle** — create `content/webapps/<slug>/index.md`, modelled on an existing bundle (`content/webapps/dmsp-like-econ/` for GEE, `content/webapps/expdpy-explore/` for Streamlit): `title` = the English title; `date` = today; `summary`; `app_url` = the app URL; `platform`; `region` (if any); `topic`; the `_build: {render: never, list: always}` block; `links:` (the tutorial, or the package page `/software/<pkg>/`; if the GEE source URL is known, record it only as the front-matter comment `# Source code (GEE), not shown on the site: <url>`); and the body line `**Cite as:** Mendez, C. (<year>). Google Earth Engine Application.` (prepend co-authors if given, e.g. `Kanyama, Y., & Mendez, C. (<year>). …`). The `/webapps/` grid sorts by `date`, newest first.
3. **ES/JA bundles** — create `content/es/webapps/<slug>/index.md` and `content/ja/webapps/<slug>/index.md` with `title`, `summary`, `links[].name` and the citation line **translated** (ES = neutral Latin American Spanish, formal `usted`, `**Cite como:** … Aplicación de Google Earth Engine.`; JA = です・ます, `**引用:** … Google Earth Engine アプリ。`) per `.claude/skills/translate-content/references/glossary.md`. Keep `date`/`app_url`/`platform`/`region`/`topic`/`_build`/all URLs/`icon`/`icon_pack` identical across languages.
4. Add `{ slug: "<slug>" }` to the `APPS` array in `scripts/capture-dashboard-screenshots.cjs` (add `url: "<App URL>"` when it is not a `…projects.earthengine.app/view/<slug>` app).
5. Capture the thumbnail: `node scripts/capture-dashboard-screenshots.cjs --slug <slug>` (writes `featured.jpg` into all three bundles; needs Playwright — `npx playwright install chromium` if missing). **Eyeball the result**; if the app opens on a spinner/intro panel, re-run with a larger `--wait <ms>` (default 10000).
6. **Verify** — build with the pinned Hugo (0.96–0.119 window) and confirm that the new card appears on `/webapps/`, `/es/webapps/` and `/ja/webapps/` with its thumbnail, that it opens the app in a new tab, that the dropdown filters find it, and that no `public/webapps/<slug>/` page was rendered. Then commit the `APPS` edit, the 3× `index.md` and the 3× `featured.jpg` together.

## Re-capture / fix a thumbnail

`node scripts/capture-dashboard-screenshots.cjs --slug <slug>` regenerates just that one across all three bundles — use it whenever an app changes, or after a previously-broken app is fixed on its host.
